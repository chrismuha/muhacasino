# Muha Casino

A polished, category-based game library for:

- Big Money Deluxe
- Neon Slots
- Pretty Penny
- Lucky Hall Bingo

The home screen includes an automatic featured-game slider, horizontal game rails,
and category browsing. The original repositories remain independent. This
repository contains standalone copies of each game under `games/`.

## Run locally

```sh
npm start
```

Then open the local address printed in the terminal.

## Validate JavaScript

```sh
npm run check
```
