# Change List

## Current version — TBD

### Gameplay

- Added Growing Penny Wild exclusively to Pretty Penny. On eligible paid and free reel spins, a natural Penny Wild can grow across all five cells of one random row for the current result. The saved trigger setting defaults to 3% and can be adjusted or disabled. Active paylines pay from the expanded grid; existing line awards never decrease, special-symbol rows and jackpot displays are protected, and growth increases effective returns beyond Regular Win Odds.
- Multicolor Wilds now have a 15M cash value in new and saved deals. They can be banked for one play, used for payments, or played in any color, including completing a set together.

### Help and support

- Added a compact Bug Report button with a bug icon inside Help that opens the issue-report instructions and email template.
- Added a Fixed section in Help Known issues with How we fixed it explanations and user-facing notes for completed fixes.
- Added a shared user-guide index for all eight casino games, with current-version labels, quick starts, detailed-rule directions, and release-history links. Help and the game-library footer link to the guides; Sorry! and Yahtzee also have direct guide and release-history links.

### Interface and accessibility

- Consolidated Monopoly Deal's completed changes under v1.6.0, the next version after v1.5.0, while preserving older release history.
- Discard stays hidden when no hand card is selected. Selecting cards restores Discard and its selected-card count.
- Elapsed game time pauses while the browser tab or window is inactive, resumes on return, and preserves paused time across reloads.
- Phone Bank, Play, Flip, Discard, and Pass controls retain 48-pixel circles. Normal phone play uses compact 14-pixel labels in two columns at widths of at least 390 pixels; enlarged reading views keep larger labels. Browsing keeps all action slots in place with unavailable actions dimmed and explained, so card options do not shift the center preview or hand.
- Phone elapsed time sits between the player name and Tools, clear of deck counts and card previews. Normal play on phones at least 390 pixels wide uses two action columns with 48-pixel tap targets and compact labels, keeping the hand visible when selecting or clearing cards. Enlarged reading views retain scrolling.
- Phone tables use compact populated property previews and opponent summaries. Windows up to 700 pixels tall place Bank beside Properties and cap the center preview, keeping full-sized hand cards visible. The recurring mobile scrolling report remains awaiting verification on the original device.
- Redesigned New game with aligned headers, consistent field sizes, a visible step indicator, and a fixed navigation row across Players, Names, and Review. Only the form content scrolls above the keyboard, without shrinking labels or hiding instructions. Switching opponent modes keeps Players in place and clears generated computer names from human seats.
- Reduced the casino header arrows to compact artwork while preserving their existing navigation controls and touch targets.
- Short desktop windows remove excess padding above the hand while preserving selected-card lift and focus clearance. Very short windows also tighten action spacing and use a compact elapsed-time badge. The 800 by 450 and 800 by 500 layouts fit without vertical page scrolling when selecting properties, actions, money, or wilds.
- Table tools has a centered heading below its Close button.
- Tools opens Manage, Wilds, Settings, Undo, Clear, and History in a separate dialog. Close or Escape returns to the table, and choosing a tool closes the dialog before continuing. Utility button rows no longer add height to the game.

### Reliability

- Confirmed Monopoly Deal mobile scrolling is fixed, with the completed layout corrections described in Help and the game guide.
